About This Viewer

      

        

          
🛸 Voyager Program

          
NASA's Voyager 1 and 2 spacecraft launched in 1977 and conducted flybys of Jupiter, Saturn, Uranus, and Neptune. Together they captured over 70,000 images of the outer solar system.

        

        

          
📁 VICAR Format

          
VICAR (Video Image Communication And Retrieval) is NASA's standard format for planetary image data. Files contain a text label with metadata followed by raw binary pixel data in BSQ, BIL, or BIP organization.

        

        

          
🔭 Data Source

          
Images are fetched live from NASA's OPUS (Outer Planets Unified Search) system and PDS (Planetary Data System) Imaging Node. All data is in the public domain.

        

        

          
⚙️ VICAR Fields

          
    
            
  • LBLSIZE — label size in bytes
    • 
            
  • NL/NS/NB — lines, samples, bands
    • 
            
  • FORMAT — pixel type (BYTE, HALF, REAL…)
    • 
            
  • ORG — data org (BSQ, BIL, BIP)
    • 
            
  • INTFMT — byte order (LOW/HIGH)
